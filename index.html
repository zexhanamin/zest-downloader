Browser extension

The extension hands downloads and magnet links to Zest. It talks to the app on 127.0.0.1:6543 — Zest has to be running for capture to work.

  1. Open chrome://extensions
  2. Turn on Developer mode (top right)
  3. Click Load unpacked and pick the folder below

Launches Chrome / Edge / Brave in a separate throwaway profile with the extension already loaded. Your normal profile, logins and bookmarks are untouched.
